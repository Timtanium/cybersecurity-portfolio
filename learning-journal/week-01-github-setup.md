
# Week 01: Cybersecurity Portfolio Setup

## 1. Overview

This week marks the beginning of my structured
cybersecurity development and portfolio-building
journey.

The objective was to establish a professional
documentation and version-control environment.

## 2. Learning Objectives

- Understand Git and GitHub.
- Configure Git on Windows.
- Understand repositories and commits.
- Create a GitHub portfolio.
- Learn Markdown documentation.
- Publish a local project to GitHub.

## 3. Tools and Technologies

| Tool | Purpose |
|---|---|
| Git | Version control |
| Git Bash | Git command-line operations |
| GitHub | Remote repository hosting |
| VS Code | Code editing and documentation |
| Windows 11 | Host operating system |

## 4. Practical Activities

1. Created and configured a GitHub account.
2. Installed and verified Git.
3. Configured Git username and email.
4. Enabled GitHub email privacy.
5. Created a cybersecurity portfolio folder.
6. Created a README.md file.
7. Initialized a local Git repository.
8. Staged and committed the README file.
9. Created a remote GitHub repository.
10. Configured GitHub authentication.
11. Successfully pushed the local repository
    to GitHub.

## 5. Commands Practised

```bash
git --version
git config --global --list
git init
git status
git add README.md
git commit -m "Initial cybersecurity portfolio documentation"
git log -1
git remote -v
git push -u origin main
```

## 6. Challenges Encountered

- Git Bash paste functionality initially failed.
- GitHub rejected the initial authentication attempt.
- Git Credential Manager browser authentication
  resolved the GitHub push authentication issue.

## 7. Key Lessons Learned

- Git and GitHub serve different purposes.
- Git tracks changes to project files.
- Commits preserve project history.
- Remote repositories allow projects to be
  published and shared.
- GitHub supports browser-based authentication
  through Git Credential Manager.
- Technical documentation is an important
  part of professional cybersecurity work.

## 8. Outcome

Successfully created and published my first
cybersecurity portfolio repository.
